# MNIST 손글씨 분류기 (PyTorch)

28×28 흑백 손글씨 이미지를 보고 0~9 중 어떤 숫자인지 맞히는 모델.

## 파일 구조

| 파일 | 역할 |
|------|------|
| `model.py` | 모델 정의 (SimpleMLP, SimpleCNN) |
| `data.py` | MNIST 다운로드·정규화·DataLoader |
| `train.py` | 학습 루프 + 체크포인트 저장 |
| `predict.py` | 숫자별 정확도 + 오답 이미지 저장 |

## 설치

```bash
pip install -r requirements.txt
```

## 실행

```bash
python train.py                        # CNN, 5 epoch (기본)
python train.py --model mlp --epochs 3 # MLP로 빠르게 비교
python predict.py                      # 오답 분석
```

첫 실행 때 `data/` 폴더로 MNIST(약 11MB)를 자동 다운로드한다.

## 실측 성능 (2026-09-10, M시리즈 Mac / MPS / 5 epoch 동일 조건)

| 데이터셋 | 모델 | 파라미터 | 테스트 정확도 | 틀린 개수 | 학습 시간 |
|---------|------|---------|-------------|----------|----------|
| MNIST | MLP | 235,146 | 97.75% | 225장 | 21초 |
| MNIST | CNN | 468,202 | **99.51%** | **49장** | 40초 |
| FashionMNIST | MLP | 235,146 | 83.74% | 1,626장 | 22초 |
| FashionMNIST | CNN | 468,202 | **91.22%** | **878장** | 35초 |

같은 코드·같은 조건인데 MNIST 99.51% → FashionMNIST 91.22%.
오답은 49장에서 878장으로 **18배**. MNIST가 쉬웠던 것이지 모델이 좋았던 게 아니다.

CNN이 MLP를 이기는 폭도 커진다 (MNIST +1.76%p, Fashion +7.48%p).
문제가 어려워질수록 구조의 차이가 벌어진다.

## FashionMNIST 클래스별 정확도 (CNN)

| 클래스 | 정확도 | | 클래스 | 정확도 |
|-------|-------|--|-------|-------|
| 바지 | 98.70% | | 드레스 | 91.70% |
| 가방 | 98.30% | | 풀오버 | 89.00% |
| 스니커즈 | 97.80% | | 코트 | 87.60% |
| 샌들 | 97.60% | | 티셔츠 | 87.10% |
| 앵클부츠 | 95.90% | | **셔츠** | **68.50%** |

혼동 Top 3: 셔츠→티셔츠 131장, 셔츠→코트 91장, 티셔츠→셔츠 76장.
오답의 절반 가까이가 '상의 4종(셔츠·티셔츠·풀오버·코트)' 안에서 발생한다.
28x28 흑백에서는 소매 길이와 단추가 뭉개져 사람도 구분하기 어렵다.

## 주요 옵션

| 옵션 | 기본값 | 설명 |
|------|-------|------|
| `--model` | `cnn` | `cnn` 또는 `mlp` |
| `--epochs` | 5 | 전체 데이터를 몇 번 반복할지 |
| `--batch-size` | 128 | 한 번에 처리할 이미지 수 |
| `--lr` | 1e-3 | 학습률 |
| `--no-augment` | off | 회전·이동 증강 끄기 |
| `--num-workers` | 2 | 데이터 로딩 프로세스 수 (문제 생기면 0) |

## 코드 읽는 순서 (학습용)

1. `data.py` — 이미지가 어떻게 숫자 텐서가 되는지
2. `model.py` — 784개 입력이 10개 출력으로 줄어드는 과정
3. `train.py`의 `run_epoch()` — 순전파 → 손실 → 역전파 → 가중치 수정, 이 4줄이 딥러닝의 전부
4. `predict.py` — 어떤 숫자를 왜 헷갈리는지 (4↔9, 3↔5, 7↔1이 단골)
