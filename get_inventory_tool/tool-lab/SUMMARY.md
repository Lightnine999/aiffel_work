## 확인된 것

1. **하네스가 막는 범위:** 허용 목록이 있는 값(창고 코드)과 질문에 없는 값(지어낸 SKU)은 하네스가 조회 전에 막습니다. 로그에서 실제 조회 0회로 확인했어요.
2. **하네스가 못 막는 것:** 모델이 여전히 잘못된 호출을 시도합니다. 하네스는 막을 뿐 모델의 판단은 바꾸지 못합니다.
3. **재현성:** 같은 조건으로 두 번 이상 돌려도 결과가 같았습니다 (01~04, 07~08, 09~10). `temperature=0`이라 예상된 결과입니다.
4. **원가 누출:** 모든 조건에서 원가는 답에 나오지 않았습니다. 다만 도구 자체가 원가를 주지 않아서 생긴 결과이고, 응답 필터(`filter_response`)는 별도로 단위 테스트로 확인했습니다.

## 한계

- 모든 트레이스는 질문당 1회 실행입니다. 모델이 확률적으로 다른 답을 낼 가능성은 측정하지 않았어요.
- 도구 구현은 가짜입니다. 어떤 SKU를 넣어도 재고 7을 돌려줍니다.
- 회귀 테스트(`test_regression.py`, 11개)와 변형 실험(`mutation_check.py`, M1~M6)은 하네스 계층만 확인합니다. 모델의 행동은 검증하지 않습니다.
- `trace-09`는 원래 `trace-10`을 옮겨 적은 파일입니다. 번호가 연속되도록 정리한 결과입니다.
